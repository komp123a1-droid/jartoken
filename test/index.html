    Simulator (mock)

    Ubacuje lažnu transakciju kroz isti parser kao pravi Helius webhook. Prazan wallet = nasumični holder. Radi samo u MOCK modu.

    Provera walleta

    Isto što vidi posetilac sajta: da li je opsovao (pa nema dropova 24h), koliko drži, procena sledećeg dropa, neisplaćeni saldo, istorija isplata.

    Agnes outbox

    Poslednjih 20 poruka koje je Sestra Agnes poslala ili bi poslala (status log = token nije podešen, samo zapisano). Potreban admin token.

    Isplate

    Drop ide automatski na svakih 15 min (PAYOUT_EVERY_MIN) svim čistim holderima (≥ 100.000 $JAR, bez prodaje u poslednjih 24h — SIN_WINDOW_HOURS). Prodaja = bez dropova 24h i gubi neisplaćeni saldo (vraća se u teglu). Lični saldo se šalje kad dostigne 0,001 SOL. Probni drop sa ove strane je uvek dry run — ništa se ne šalje. Prave isplate idu samo preko CLI-ja (npm run collect -- --send) ili automatski ako je DRY_RUN=false.

    Spremnost za launch (preflight)

    Backend sam proverava podešavanja. ✓ ok · ✗ fali · — ne važi / preskočeno.

    —

      Launch ček-lista

      1. Napravi jar wallet (hot wallet, drži samo mali iznos za dropove — nikad ceo trezor).
      2. Launch na pump.fun sa jar walletom kao creator (creator fee ide u teglu).
      3. U .env upiši: MINT, PAYOUT_KEYPAIR, EXCLUDED_WALLETS (bonding curve, pool, dev, burn), HELIUS_API_KEY, WEBHOOK_SECRET, TG_BOT_TOKEN / TG_CHAT_ID (proveri: npm run tg), X_API_KEY / X_API_SECRET / X_ACCESS_TOKEN / X_ACCESS_SECRET (proveri: npm run x).
      4. Helius webhook: tip enhanced, account = mint, URL https://<tunel>/webhook/helius, auth header = WEBHOOK_SECRET.
      5. MODE=live, DRY_RUN=true prvi dan.
      6. Proveri probnu isplatu ovde (sekcija Isplate): grešnici nisu na listi, iznosi imaju smisla.
      7. DRY_RUN=false.
      8. npm run collect -- --send ili sačekaj sledeći drop (na svakih 15 min, PAYOUT_EVERY_MIN). Prodaja = bez dropova 24h (SIN_WINDOW_HOURS) i gubi neisplaćeni saldo.
      Klejm fee-jeva: automatski pre svake isplate (CLAIM_FEES=true), iz oba vaulta (bonding curve + PumpSwap). Testirano na pravim pump.fun programima kloniranim sa mainneta: npm run pump-validator && npm run pump-test.

      Konfiguracija

      Iz /admin/config. Tajne se nikad ne vraćaju — samo da li su podešene (*Set).
